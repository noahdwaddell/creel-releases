# Creel

**Just creel it.**

Creel is a fast, private file converter for Windows, macOS, and Linux. Convert documents, images, and video — all on your own machine. No uploads. No account. No ads.

## What Creel converts

**Documents**
DOCX, XLSX, PPTX, ODT, ODS, ODP, TXT → PDF (and back)

**Images**
JPG, PNG, GIF, TIFF, HEIC — convert between any of these

**Video**
MP4, MKV, MOV, WEBM — convert between any of these

## Privacy

Creel does not upload your files anywhere. Everything runs locally on your machine. There is no server. There is no account required. Your files are yours.

---

## Windows installation note

Windows may show a SmartScreen warning when you run the installer ("Windows protected your PC"). This happens because Creel is not yet signed with a paid certificate — not because anything is wrong with it.

To get past it: click **"More info"** → **"Run anyway"**.

This warning will go away in a future release once code signing is in place.
